# Learn Path

A learning platform for BCA, BBA, BCom, MCA & MBA students.

## How to run locally

Follow these steps:

```sh
# Step 1: Clone the repository
git clone <YOUR_GIT_URL>

# Step 2: Navigate to the project directory.
cd learnpath

# Step 3: Install the necessary dependencies.
npm install

# Step 4: Start the development server
npm run dev
```

## Technologies used

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- Supabase

## Deployment

Deploy using Vercel, Netlify, or any static hosting service.

For Supabase functions, deploy via Supabase CLI.
